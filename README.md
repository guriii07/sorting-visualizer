# 📊 Java Sorting Visualizer

A sophisticated, dark-themed desktop application built with Java (Swing) that visualizes how various sorting algorithms work in real-time. This project was designed to help students and developers understand algorithmic logic through interactive animation.

## 🚀 Features

* **8 Sorting Algorithms:** Includes both comparison-based and non-comparison based algorithms.
* **Real-Time Visualization:** Watch the sorting process step-by-step.
* **Dark Mode UI:** A clean, modern interface that is easy on the eyes.
* **Interactive Controls:**
    * **Start/Pause/Resume:** Full control over the animation flow.
    * **Speed Control:** Adjustable slider to slow down or speed up the sorting.
    * **Reset:** Instantly generate a new random array.
    * **Algorithm Selector:** Seamlessly switch between algorithms.
* **Color-Coded Feedback:**
    * 🟦 **Blue:** Default (Unsorted)
    * 🟨 **Yellow:** Being Compared
    * 🟥 **Red:** Being Swapped / Overwritten
    * 🟩 **Green:** Sorted Position

## 🛠️ Algorithms Implemented

1.  **Bubble Sort** - The classic "bubbling up" approach.
2.  **Selection Sort** - Finds the minimum and places it at the beginning.
3.  **Insertion Sort** - Builds the sorted array one item at a time.
4.  **Merge Sort** - Divide and conquer (recursive).
5.  **Quick Sort** - Partitioning around a pivot (recursive).
6.  **Counting Sort** - Non-comparison integer sorting.
7.  **Radix Sort** - Digit-by-digit sorting.
8.  **Bucket Sort** - Distributes elements into buckets.
